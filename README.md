# ジオ遍路（試作）

四国の遍路道と地質図を重ねて見る、スマートフォン向けの地図アプリ（Webアプリ）です。
応用地質学会 中国四国支部の事業「ジオ遍路」のために作りました。

- 地図をタップすると、その場所の地質（岩石と時代）がわかります
- 現在地の地質と、遍路道・いちばん近い札所までの距離がわかります
- 八十八ヶ所霊場それぞれの足もとの地質の一覧
- 歩いた道を記録して、GPXファイルで送れます
- ホーム画面に置けば、電波の届かない所でも遍路道と札所、一度見た範囲の地図を表示できます

## 出典

- 地質図：産業技術総合研究所 地質調査総合センター「20万分の1日本シームレス地質図V2」「5万分の1地質図幅」
- 背景図：地理院地図（国土地理院）を加工して使用（地理院タイル 淡色地図）
- 遍路道・札所の位置：四国遍路世界遺産登録推進協議会 提供（「遍路道とトイレ位置案内図」。地理院地図（国土地理院）を加工して作成）。掲載は同協議会の承認を受けて行っています
  - 遍路道は「みち案内表示シートで案内するルート」で、遍路の文化的背景を持たない道を含みます。元の図面の縮尺の関係で、地図上の道路とずれる所があります。実際の道路状況や交通規制にしたがって歩いてください。
